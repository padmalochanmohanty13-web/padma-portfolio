# Padmalochan Mohanty — Portfolio

A modern, responsive developer portfolio built with **React.js, Tailwind CSS, Framer Motion, and Lucide React**.

## Tech Stack

* React.js
* Tailwind CSS
* JavaScript
* Framer Motion
* Lucide React
* Vite

## Highlights

* Responsive modern UI
* Smooth animations
* Project showcase
* Skills & experience
* Education & certifications
* Resume & contact section

## Run Locally

```bash
git clone https://github.com/padmalochanmohanty13-web/padmadev-portfolio.git
cd portfolio
npm install
npm run dev
```
